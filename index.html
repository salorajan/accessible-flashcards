Accessible Flashcards for the Blind

This application is designed specifically for blind and visually impaired users. It provides a keyboard-only experience with full Text-to-Speech (TTS) support, ensuring that studying remains independent and accessible.

Download & Install

Download the Windows application and the sample card set below:

Download app.exe (Windows)

Required: Download flashcards.json and place it in the same folder as the exe.

How to Use (Keyboard Shortcuts)

Spacebar: Hear Question / Hear Answer
Y Key: Mark as Correct
N Key: Mark as Incorrect
R Key: Repeat Audio
Q Key: Quit & View Score

Create Your Own Topics

Edit the flashcards.json file with any text editor. Use the AI prompt below to generate new content instantly:

"Act as an educational content creator. I need a flashcard set in JSON format for the topic: [INSERT TOPIC]. Please provide exactly 10 cards. The format MUST be a list of objects where each object has a 'question' and an 'answer' key. IMPORTANT: Write all math and complex terms exactly how they should be SPOKEN (e.g., use 'squared' instead of '^2'). Return ONLY the raw JSON code block."

Installation Note (SmartScreen)

If Windows displays a "Protected your PC" warning:

  • Click "More info"
  • Click "Run anyway"
