Accessible Flashcards for the Blind

A keyboard-driven, offline-first flashcard application designed specifically for visually impaired users. Built with Python and pyttsx3.

Download

Download the latest Windows executable and the sample SAT Math cards:

Download app.exe (Windows)

Note: Also download flashcards.json and keep it in the same folder as the exe.

How to Use

The app is 100% accessible via keyboard. No mouse required!

  • Spacebar: Hear the Question / Hear the Answer.
  • Y Key: Mark as Correct.
  • N Key: Mark as Incorrect.
  • R Key: Repeat the current audio.
  • Q Key: Quit and hear your score.

For Families: Create Your Own Cards

You can create custom study sets for any topic using a simple JSON format. See the Full Manual for instructions and an AI prompt to help you generate content.
