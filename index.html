How to Use

This app is 100% keyboard-accessible. After uploading your JSON file:

  • Spacebar: Read Question / Read Answer
  • 'Y' Key: Mark as Correct
  • 'N' Key: Mark as Incorrect
  • 'R' Key: Repeat Audio
  • 'Q' Key: Finish Session

Create Your Own Content

Use any AI (ChatGPT/Gemini) with this prompt to get new cards:

"Act as an educational content creator. I need 10 flashcards in JSON format for: [TOPIC]. Return only a JSON list of objects with 'question' and 'answer' keys. Write math/complex terms exactly how they should be spoken (e.g., 'x squared')."
